## 💻 Usage

### CLI Interface

```bash
# Analyze a word
./bin/alphabet-engine analyze TRUTH

# Compare two words
./bin/alphabet-engine compare FIRE WATER

# Generate offspring words
./bin/alphabet-engine mate SEED SOIL

# Apply advanced operators
./bin/alphabet-engine transform CHAOS

# Get letter information
./bin/alphabet-engine letter A

# Interactive mode
./bin/alphabet-engine interactive
```

### Python API

```python
from core.alphabet_engine import AlphabetEngine

# Initialize engine
engine = AlphabetEngine()

# Analyze a word
result = engine.analyze_word("COMMUNION")

print(f"Gematria: {result['gematria']}")
print(f"I/O Ratio: {result['io_ratio']:.2%}")
print(f"Dominant Element: {result['dominant_element']}")
print(f"Element Balance: {result['element_balance']}")
```

### Word Mating

```python
from core.word_mating import WordMating

mating = WordMating()
result = mating.mate_words("SEED", "SOIL", max_candidates=5)

for offspring in result['offspring']:
    print(f"{offspring['word']} (Score: {offspring['score']:.1%})")
```

### LLM Integration

```python
from integrations.llm_wrapper import AlphabetLLM

llm = AlphabetLLM(model="gpt-4.1-mini")

# Analyze word with LLM insights
result = llm.analyze_word_with_llm("TRUTH")
print(result['llm_analysis'])

# Generate offspring with LLM validation
result = llm.generate_offspring_with_llm("FIRE", "WATER")
print(result['llm_validation'])
```

### System Integrations

```python
# CERBERUS Integration
from integrations.cerberus_bridge import CerberusAlphabetBridge

bridge = CerberusAlphabetBridge()
```

### Vowel States (Consciousness)

| Letter | State | Element | Gematria | Description |
|--------|-------|---------|----------|-------------|

| I | Identity | Fire | 10 | Self, seed, binary 1 |
| O | Unity | Water | 70 | Womb, circle, binary 0 |
| U | Binding | Water | 400 | Union, nourishment, flow |

### Consonant Classes (Operators)

| Class | Letters | Function | Element |
|-------|---------|----------|---------|
| Container | B, D, G | Hold, store, frame | Earth |
| Bridge | H, R, Y | Shift, link, connect | Air/Water/Spirit |
| Cutter | K, T, X | Slice, separate, define | Fire/Earth/Spirit |
| Wave | M, N, W | Oscillate, resonate, carry | Water |
| Portal | Q, Z | Open/close cycles | Spirit/Fire |
| Flare | F, S, V | Radiate, express, project | Fire |
| Anchor | C, J, P | Fixed points, signals | Earth |
| Binder | L | Attach, merge, unify | Spirit |

### I/O Binary System

- **I = 1**: Identity, masculine, projective, seed energy
- **O = 0**: Unity, feminine, receptive, womb energy

Words with high I-ratio are projective (e.g., FIRE: 100%)  
Words with high O-ratio are receptive (e.g., LOVE: 0%)

### Element Mapping

- **Pyro (Fire)**: Friction, transformation, energy (F, S, V, I)
- **Hydro (Water)**: Flow, nourishment, binding (M, N, W, O, U, R)
- **Geo (Earth)**: Structure, boundary, containment (B, D, G, T, C, J, P)
- **Aeros (Air)**: Breath, spirit, initiation (A, E, H)
- **Mercury (Spirit)**: Transformation, liquid metal (Y, X, Q, L)
